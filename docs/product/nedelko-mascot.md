# Nedelko calendar mascot

The product owner requested a hand-drawn calendar with a smiling face, stick arms and legs, one waving hand, and oversized red cartoon shoes. This replaces the leaf as Nedelko's brand mark.

The [transparent PNG](../../frontend/assets/nedelko-mascot.png) was generated with the built-in image generation tool. It is used in the sign-in, teacher and parent headers, onboarding, empty and loading states, and the browser icon. The adjacent bilingual brand or status text supplies the accessible name. Functional leaf icons still identify environmental activities.

The illustration has a cream page, forest-green binding, dark ink outlines and red shoes. The original generated alpha is retained; there is no background rectangle. The asset is local to the frontend and requires no external image host or build step.
