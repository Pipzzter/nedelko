# Nedelko calendar mascot

The product owner requested a hand-drawn calendar with a smiling face, stick arms and legs, one waving hand, and oversized red cartoon shoes. This replaces the leaf as Nedelko's brand mark.

The [transparent PNG](../../frontend/assets/nedelko-mascot.png) was generated with the built-in image generation tool. It is used in the sign-in, teacher and parent headers, onboarding, empty and loading states. The adjacent bilingual brand or status text supplies the accessible name. Functional leaf icons still identify environmental activities.

The [browser icon](../../frontend/assets/nedelko-favicon.png) is a separate calendar-only edit made with the built-in image generation tool. It retains the smiling face and binding rings, removes the hands, arms, legs and shoes, and fills more of the square canvas for clarity at tab size. The full mascot remains unchanged elsewhere.

The illustration has a cream page, forest-green binding, dark ink outlines and red shoes. The original generated alpha is retained; there is no background rectangle. The asset is local to the frontend and requires no external image host or build step.

## Browser icon edit prompt

Input: the full mascot PNG linked above.

```text
Use case: precise-object-edit. Asset type: Nedelko browser favicon, a calendar-only variant of the existing mascot. Input image 1 is the edit target. Remove both arms, both hands, both legs, both red shoes and the waving motion marks completely. Keep only the original smiling calendar body: preserve its cream paper, forest-green top strip, two binding rings, dot eyes, curved happy smile, subtly uneven dark ink outline and hand-drawn colored-pencil texture. Close the calendar outline cleanly wherever limbs were attached. Recenter and enlarge this calendar alone on a square canvas so it fills approximately 94 percent of the available width or height, with small even transparent margins and no clipping. Optimize the simple bold face and calendar silhouette for readability at tiny browser-tab size while preserving the original character and style. Genuinely transparent alpha background, no background rectangle, no shadow. No text, letters, numbers, leaf, extra objects, limbs, shoes, badge, sticker border, or painted checkerboard. This is a separate favicon variant; the full mascot remains unchanged.
```
